Projeto 01 — Sistema de acesso e notas

Programa desenvolvido em Python que:

- Solicita nome, idade e senha;
- Valida os dados de entrada;
- Controla o acesso do usuário;
- Recebe duas notas;
- Calcula a média;
- Informa se o aluno foi aprovado, está de recuperação ou reprovado.

Tecnologias utilizadas

- Python
- Lógica de programação
- Estruturas condicionais
- Tratamento de exceções

 Objetivo

Praticar os fundamentos da linguagem Python e desenvolver minha lógica de programação por meio de projetos práticos.
